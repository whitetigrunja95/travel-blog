# Travel Blog

Учебный проект блога о путешествиях на React.

Приложение позволяет просматривать истории о путешествиях, регистрироваться и авторизоваться, редактировать профиль, создавать посты с изображениями и оставлять комментарии.

## Функциональность

### Пользователь

* регистрация
* авторизация
* выход из профиля
* просмотр данных текущего пользователя
* редактирование профиля
* смена пароля
* загрузка аватара

### Посты

* просмотр списка постов
* просмотр поста по id
* создание нового поста
* загрузка изображения поста
* просмотр комментариев к посту
* добавление комментария

### Интерфейс

* главная страница со списком историй
* страница входа
* страница регистрации
* страница профиля
* страница создания поста
* страница отдельного поста

## Установка frontend

Перейдите в папку проекта:

```bash
cd travel-blog
```

Установите зависимости:

```bash
npm install
```

### Запуск frontend

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:5173
```

## Установка backend

Перейдите в папку server:

```bash
cd server
```

Установите зависимости:

```bash
npm install
```

### Запуск backend

```bash
node sever.js
```

После запуска сервер будет доступен по адресу:

```text
http://127.0.0.1:8000
```

## Хранение данных

В проекте реализовано сохранение данных в JSON-файл.

Сохраняются:

* зарегистрированные пользователи
* профиль пользователя
* аватар пользователя
* посты
* изображения постов
* комментарии
* пароль пользователя

Сервер автоматически создаёт:

```text
data/db.json
```

при первом запуске.
